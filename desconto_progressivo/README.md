# Desconto Progressivo

Programa desenvolvido em Python para calcular descontos de acordo com o valor total de uma compra.

## Regras

- Compras menores que R$ 200: desconto de 5%
- Compras de R$ 200 até menos de R$ 300: desconto de 10%
- Compras de R$ 300 ou mais: desconto de 15%

## Funcionamento

O programa solicita o valor total da compra, identifica a porcentagem de desconto correspondente e calcula o valor final que o cliente deverá pagar.

## Tecnologias utilizadas

- Python
- VS Code
